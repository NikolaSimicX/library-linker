# Library Linker

BiblioTeka je MVP web aplikacija za evidenciju pozajmljenih knjiga u biblioteci — zamena za papirne sveske.

Šta radi: registracija i prijava, forma za unos pozajmice, spisak članova sa brojem pozajmica, i stranica detalja člana sa knjigama koje je pozajmio.
Dizajn: topla bibliotečka paleta, tamno zelena i braon boja
Testirano: registracija, prijava/odjava, unos pozajmice i prikaz podataka — sve provereno u pregledaču bez grešaka.
Tipovi Korisnika: Posetilac (neprijavljen) — vidi početnu stranicu i katalog knjiga. - Član (prijavljen) — unosi pozajmice, vidi sve članove i detalje, označava knjigu kao vraćenu.

Tehnologije koriscene:
- HTML
- CSS
- JavaScript
- React
- TypeScript
- Supabase

Funkcionalnosti:
1. Kloniranje repositorijuma
2. Instalacija zavisnosti
3. Konfiguracija promenljiva okruzenja
4. Pokrenuti Dev Server
